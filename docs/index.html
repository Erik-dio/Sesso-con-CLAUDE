Simulazione Monte Carlo

Lancia migliaia di scenari simulati basati sui dati storici delle azioni. Scopri come potrebbe evolvere il tuo portafoglio.

  • Fan chart di tutte le traiettorie possibili
  • VaR al 95% e 99% di confidenza
  • Distribuzione dei valori finali (istogramma)
  • Scenario migliore e peggiore
  • Moto Browniano Geometrico (GBM) con Cholesky

Quick start

Come si avvia

Hai bisogno di Python 3.11+ e Node.js. Tre comandi e sei operativo.

1

Clona la repo

Scarica il progetto in locale con Git.

2

Esegui il setup

Lo script crea il venv Python e installa tutte le dipendenze automaticamente.

3

Avvia i due server

Backend su porta 8000, frontend su porta 3001. Apri il browser e inizia.

git clone https://github.com/Erik-dio/Sesso-con-CLAUDE.git
cd Sesso-con-CLAUDE

# Setup completo (venv + npm install)
bash setup.sh

# Terminal 1 — backend
./venv/bin/python -m uvicorn backend.main:app --reload --port 8000

# Terminal 2 — frontend
cd frontend && npm start
